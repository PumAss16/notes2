# 1) Навигация и работа с файлами

## 1.1) `find` - поиск файлов

__`find` ищет файлы по любым критериям: имя, размер, дата изменения (дни), права.__

`find /путь/где/искать -name "имя_файла"`

Найти все файлы .log в /var/log, измененные за последние 7 дней
`find /var/log -name "*.log" -mtime -7`

Найти все файлы больше 100 МБ
`find / -size +100M`

Найти все файлы с правами 777 (потенциально опасные)
`find / -perm 777`

Найти и удалить все пустые директории
`find . -type d -empty -delete`

__Флаги__
`-type f` - только файлы
`-tipe d` - только директории
`-mtime` - время изменения (дни)
`-mmin` - время изменения (минуты)
`-size` - (+100M - больше 100 МБ, -1G - меньше 1 Gb)
`-exec` - выполнить над каждым найденным файлом 

## 1.2 `locate` - быстрый поиск по базе данных
__`locate` работает намного быстрее `find`, потому что ищет по заранее подготовленной базе данных.__

__Обновить базу данных (делается раз в день автоматически)__
`sudo updatedb`

__Найти все файлы, содержащие слово "nginx"__
`locate nginx`

__Важно:__ `locate` не видит файлы, созданные после последнего обновления базы.


## 1.3) `tree` — показать структуру директорий в виде дерева

__Показать структуру текущей директории на 2 уровня вглубь__
`tree -L 2`

__Показать только директории__
`tree -d`

## 1.4) `ln` - создание ссылок

__Жесткая ссылка — это еще одно имя для того же файла. Символическая ссылка — это "ярлык".__

__Создать жесткую ссылку__
`ln original.txt hardlink.txt`

__Создать символическую ссылку__
`ln -s /путь/к/оригиналу symlink`


|Характеристика |	Жесткая ссылка	Символическая ссылка|
|Указывает на... |	inode (содержимое файла)	Путь к файлу|
|Можно использовать для директорий |	Нет |	Да|
|Если удалить оригинал |	Файл остается доступен |	Ссылка "битая"|
|Занимает место |	Нет (та же inode) |	Да (несколько байт)|

## 1.5) `stat` - полная информация о файле

`stat /etc/passwd`

__Вы увидите:__

    File: — имя

    Size: — размер

    Inode: — номер inode

    Links: — количество жестких ссылок

    Access: — права в символьном и цифровом виде

    Access: — время последнего чтения

    Modify: — время последнего изменения

    Change: — время последнего изменения метаданных

## 1.6) `file` - определяет тип файла

__Linux не смотрит на расширение, он смотрит на содержимое.__

__Определить тип файла__
`file /bin/bash`        -> ELF 64-bit LSB executable
`file image.png`        -> PNG image data
`file script.sh`        -> ASCII text
