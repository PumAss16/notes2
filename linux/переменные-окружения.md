# 3) Переменные окружения

## 3.1) Что это и как посмотреть

__Переменные окружения хранят настройки для системы и приложений.__

__Посмотреть все переменные__
`env`

__Посмотреть конкретную переменную__
`echo $PATH`
`echo $HOME`
`echo $USER`

## 3.2) PATH — главная переменная для DevOps

__`PATH` содержит список директорий, где система ищет исполняемые файлы.__

__Посмотреть `PATH`__

`echo $PATH`

__Добавить свою директорию в PATH (временно, только для сессии)__

`export PATH=$PATH:/my/custom/bin`

__Сделать добавление постоянным — записать в файл `~/.bashrc`__

## 3.3) Где хранятся переменные окружения (важно!)
| __Файл__ | __Когда загружается__ | __Для кого__ |
|------|-------------------|----------|
| `/etc/environment` | При загрузке системы | Все пользователи (системные переменные) |
| `/etc/profile` | При логине | Все пользователи (интерактивный shell) |
| `~/.bashrc` | При запуске каждого нового терминала | Только текущий пользователь |
| `~/.bash_profile` | При логине (обычно в GUI не используется) | Только текущий пользователь |
| `~/.profile `| Если нет `.bash_profile` | Только текущий пользователь |

__Главное правило DevOps:__

    `export` в `~/.bashrc` — для повседневных нужд.

    Если переменная нужна демонам/сервисам — кладите её в `/etc/environment` или в systemd-юнит.

__Временно (только для текущей сессии)__
`MY_VAR="Hello"`
`echo $MY_VAR`

__Сделать переменную доступной для дочерних процессов__
`export MY_VAR="Hello"`

__Удалить переменную__
`unset MY_VAR`
