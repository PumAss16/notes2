# Git — Шпаргалка (только команды)

## 1. Базовые
| Команда | Что делает |
|---------|------------|
| `git init` | Создать репозиторий |
| `git status` | Проверить состояние |
| `git add <файл>` | Добавить файл в индекс |
| `git add .` / `-A` | Добавить всё |
| `git add -p` | Добавить частями (интерактивно) |
| `git commit -m "..."` | Коммит с сообщением |
| `git commit -a -m "..."` | `add` + `commit` для отслеживаемых |
| `git commit --amend` | Изменить последний коммит |
| `git push` | Отправить в удалённый репо |
| `git push origin main` | Отправить ветку main |
| `git push -u origin ветка` | Отправить + привязать (upstream) |
| `git push --tags` | Отправить теги |
| `git push --force` | Перезаписать **(ОПАСНО)** |
| `git push --force-with-lease` | Безопасный форс |
| `git push origin :ветка` | Удалить ветку на сервере |
| `git pull` | Забрать + смержить |
| `git pull --rebase` | Забрать + rebase |
| `git clone <url>` | Склонировать репо |
| `git clone --depth 1` | Только последний коммит |

---

## 2. Ветки
| Команда | Что делает |
|---------|------------|
| `git branch` | Список локальных веток |
| `git branch -r` | Список удалённых |
| `git branch -a` | Все ветки |
| `git branch новая` | Создать ветку |
| `git branch -d ветка` | Удалить (безопасно) |
| `git branch -D ветка` | Удалить (принудительно) |
| `git branch -m старое новое` | Переименовать |
| `git checkout ветка` | Переключиться |
| `git checkout -b новая` | Создать + переключиться |
| `git checkout -- файл` | Отменить изменения в файле |
| `git switch ветка` | Переключиться (новое) |
| `git switch -c новая` | Создать + переключиться (новое) |
| `git restore файл` | Отменить изменения (новое) |
| `git restore --staged файл` | Убрать из индекса |

---

## 3. Слияние и перенос
| Команда | Что делает |
|---------|------------|
| `git merge ветка` | Слить ветку в текущую |
| `git merge --no-ff ветка` | Всегда с merge-коммитом |
| `git merge --abort` | Отменить слияние |
| `git rebase ветка` | Перенести коммиты поверх ветки |
| `git rebase -i HEAD~N` | Интерактивный rebase (объединять/править) |
| `git rebase --continue` | Продолжить после конфликта |
| `git rebase --abort` | Отменить rebase |
| `git cherry-pick хеш` | Взять коммит из другой ветки |
| `git cherry-pick хеш1..хеш2` | Взять диапазон |
| `git cherry-pick --continue` | Продолжить после конфликта |
| `git cherry-pick --abort` | Отменить |

---

## 4. Информация
| Команда | Что делает |
|---------|------------|
| `git log` | История коммитов |
| `git log --oneline` | Сокращённо |
| `git log --graph` | С визуализацией веток |
| `git log --author="Имя"` | По автору |
| `git log --since="2 days"` | За последние 2 дня |
| `git log --grep="текст"` | Поиск по сообщению |
| `git log -p` | С изменениями |
| `git diff` | Различия (рабочая vs индекс) |
| `git diff --staged` | Индекс vs последний коммит |
| `git diff ветка1 ветка2` | Между ветками |
| `git diff --stat` | Только статистика |
| `git show хеш` | Информация о коммите/теге |
| `git blame файл` | Кто изменил каждую строку |
| `git describe` | Ближайший тег |

---

## 5. История (откат)
| Команда | Что делает |
|---------|------------|
| `git reset --soft HEAD~1` | Откатить коммит, изменения в индексе |
| `git reset --mixed HEAD~1` | Откатить, изменения в рабочей (по умолчанию) |
| `git reset --hard HEAD~1` | **Полностью удалить коммит (НЕВОЗВРАТНО)** |
| `git reset --hard HEAD` | Отменить ВСЕ незакоммиченные изменения |
| `git reset --hard origin/main` | Сбросить до состояния удалённой |
| `git revert хеш` | **Безопасно** отменить коммит (новым коммитом) |
| `git revert HEAD~2..HEAD` | Отменить диапазон |

---

## 6. Stash (временное хранение)
| Команда | Что делает |
|---------|------------|
| `git stash` | Спрятать изменения |
| `git stash save "описание"` | Спрятать с описанием |
| `git stash list` | Список стэшей |
| `git stash pop` | Применить последний + удалить |
| `git stash apply` | Применить последний (не удалять) |
| `git stash drop stash@{0}` | Удалить стэш |
| `git stash clear` | Удалить всё |

---

## 7. Удалённые репозитории
| Команда | Что делает |
|---------|------------|
| `git remote -v` | Показать удалённые репо с URL |
| `git remote add origin <url>` | Добавить удалённый репо |
| `git remote remove origin` | Удалить |
| `git remote rename старое новое` | Переименовать |
| `git fetch` | Скачать изменения (БЕЗ слияния) |
| `git fetch --prune` | Удалить ссылки на удалённые ветки |

---

## 8. Теги
| Команда | Что делает |
|---------|------------|
| `git tag` | Список тегов |
| `git tag v1.0` | Легкий тег |
| `git tag -a v1.0 -m "..."` | Аннотированный тег |
| `git tag -d v1.0` | Удалить локально |
| `git push origin v1.0` | Отправить тег |
| `git push --tags` | Отправить все теги |
| `git push --delete origin v1.0` | Удалить тег на сервере |

---

## 9. Продвинутые
| Команда | Что делает |
|---------|------------|
| `git reflog` | Журнал HEAD (восстановить потерянное) |
| `git bisect start` | Начать поиск бага |
| `git bisect bad HEAD` | Коммит плохой |
| `git bisect good v1.0` | Коммит хороший |
| `git bisect reset` | Закончить поиск |
| `git grep "текст"` | Поиск по файлам |
| `git clean -fd` | Удалить неотслеживаемые **(ОПАСНО)** |
| `git clean -n` | Показать, что будет удалено |

---

## 10. Настройка
| Команда | Что делает |
|---------|------------|
| `git config --global user.name "Имя"` | Имя пользователя |
| `git config --global user.email "email"` | Email |
| `git config --list` | Все настройки |
| `git config --global alias.co checkout` | Создать алиас |
| `git config --global pull.rebase true` | `pull` по умолчанию с `--rebase` |

---

## 11. DevOps / CI/CD
| Команда | Что делает |
|---------|------------|
| `git diff --quiet HEAD~1 HEAD` | Есть ли изменения (0/1) |
| `git diff --name-only HEAD~1 HEAD` | Имена изменённых файлов |
| `git rev-parse HEAD` | Хеш текущего коммита |
| `git rev-parse --abbrev-ref HEAD` | Имя текущей ветки |
| `git log -1 --pretty=%B` | Сообщение последнего коммита |
| `git branch --show-current` | Текущая ветка |
| `git remote get-url origin` | URL удалённого репо |
